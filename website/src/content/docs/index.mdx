## Where this project is

This site documents the **Phase 1** daemon + CLI process-supervision MVP.
Reverse proxy, automatic SSL, native OS service install, and the GUI are
later phases — see [Roadmap & Status](/harbor/roadmap/) for exactly what's
implemented today versus what's planned.
